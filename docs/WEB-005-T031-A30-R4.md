## PROXY_TRUST_CONTRACT

- No `TRUSTED_PROXY_CIDRS`, blank value or whitespace: `app.set("trust proxy", false)` as before.
- `loopback`, explicit single IPv4/IPv6 and limited CIDR ranges: allowed.
- IPv4: CIDR must be /8 ... /32.
- Native IPv6: CIDR must be /16 ... /128.
- IPv4-mapped IPv6: CIDR must be /104 ... /128, equivalent to IPv4 /8 ... /32.
- Reject `0.0.0.0/0`, `::/0`, /1, invalid mapped IPv6 short prefixes, malformed addresses, negative/non-numeric/too-long prefixes, and empty CSV entries.
- The library patch is a necessary defense against cross-family trust errors; validation separately enforces a narrow operator policy. An operator must still ensure every allowed CIDR consists only of controlled reverse proxies.

**Compatibility:** restrictive startup validation may reject historically accepted overbroad ranges such as `fc00::/7`, or `0.0.0.0/0`. This is intentional fail-closed and requires topology review before release. A correctly configured loopback or narrow explicit reverse proxy remains supported. `req.ip` is still a primary source and may change grouping of stored HMAC source fingerprints if network trust was previously misconfigured.

## SECURITY_RISKS / ROLLBACK_PLAN

- Attack surface removed from source: vulnerable proxy-addr 2.0.7 and accepting unsafe wide/mapped CIDRs. This does **not** prove deployed production was exploitable; deployment configuration unknown.
- Residual issue: a CIDR that passes syntactic/min-prefix validation may still contain attacker-controlled hosts; operator must limit network reachability and sanitize forwarded headers.
- Rate limiting depends on HMAC fingerprint of `getRequestSource(req)`; any IP interpretation changes can shift bucket grouping. Audit logger does not independently establish true peer IP; verify reverse proxy topology separately.
- Safe rollback of a too-strict CIDR policy: refine allowlist to **precise trusted proxy peers**. Do **not** revert to proxy-addr@2.0.7 or broad `trust proxy`. An emergency `trust proxy=false` requires 00 authorization and acknowledgement of rate-limit aggregation behind a proxy.
